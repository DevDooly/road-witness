# RoadWitness Android 앱

Kotlin과 Jetpack Compose를 사용하는 Android 프로젝트의 예정 위치입니다. 현재는 계획 문서만 있으며 앱 초기화는 [1주차 실행 작업](../../docs/PLAN.md)에서 진행합니다.

## 초기화할 항목

- Android Studio 프로젝트와 재현 가능한 Gradle Wrapper
- 안정 버전으로 고정한 의존성 및 지원 OS 결정
- CameraX 녹화·프레임 분석 실험 화면
- Media3 영상 구간 내보내기 실험
- 기기별 지연·발열·녹화 공백 기록

패키지 ID는 배포 계정과 소유자가 확정되면 선택합니다. 현재 임의의 소유자 도메인을 설정하지 않습니다. 서명 파일과 로컬 SDK 경로는 Git에서 제외합니다.
