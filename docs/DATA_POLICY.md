# RoadWitness 영상과 개인정보 관리

주행 영상과 번호판, 위치, 촬영 시각은 앱의 증거 준비 기능에 필요한 자료입니다. 초기 버전은 기기 내 저장·처리를 기본으로 설계하고, 사용자가 내보내기를 실행할 때 선택한 자료를 전달합니다.

이 문서는 개발 운영 원칙입니다. 실제 배포의 개인정보 처리방침, 이용 조건과 외부 신고 요건은 배포 대상·수집 흐름이 확정되면 별도로 검토합니다.

## 저장과 삭제

- 원본 파일은 수정하지 않고 보관 여부를 사용자가 결정합니다.
- 임시 녹화는 공간 한도와 보관 기간에 따라 정리합니다. 사건 보호 구간은 검토가 끝나기 전 임의 삭제하지 않습니다.
- 번호판 자동 제안과 사용자 확인값, 위치·시각의 출처를 구분합니다.
- 앱 내부 자료 삭제와 외부 공유·저장된 사본 삭제의 범위를 화면에서 알립니다.
- 샘플 로그, 오류 보고와 분석 지표에는 실제 번호판, 좌표, 영상 경로를 기본으로 넣지 않습니다.
- 영상의 클라우드 재분석이나 모델 학습 사용은 별도 기능으로 설계하고, 사용 범위와 보관 정책을 먼저 정합니다.

## 저장소에서 제외하는 자료

| 자료 | 로컬 위치 예시 | 관리 방법 |
| --- | --- | --- |
| 원본 영상 | `data/raw/` | Git에서 제외, 필요한 보관 공간에서 별도 관리 |
| 분석·사건 자료 | `data/processed/`, `data/evidence/` | 실제 번호판·위치가 있는 파일은 Git에서 제외 |
| 신고 내보내기 | `data/exports/` | 영상·요약문·JSON 모두 Git에서 제외 |
| 위치 로그 | `data/gps/` | Git에서 제외 |
| 학습·평가 자료 | `data/datasets/` | 사용 권한과 세션별 분리 기준 관리 |
| 모델 가중치 | `ml/weights/` | Git에서 제외, 모델 버전·해시·라이선스 정보는 코드로 관리 |
| 서명 키·환경 값 | 프로젝트별 로컬 설정 | Git에서 제외 |

`.gitignore`는 새 파일의 실수 유입을 줄이는 수단입니다. 이미 추적된 파일이나 다른 이름·위치로 복사한 자료는 자동 제거하지 않으므로 커밋 목록을 확인합니다. 실제 영상에서 자른 번호판 이미지, CSV, JSON도 동일하게 취급합니다.

## 개발 자료

저장소에는 합성 예시를 우선 사용합니다. 실영상 실험은 촬영·이용 권한과 보관 범위를 확인한 자료로 진행합니다. 외부 모델과 데이터는 상업적 이용 가능 여부, 재배포, 표시 의무를 확인한 뒤 선택합니다.

공유용 화면 예시에는 번호판과 사람 얼굴, 정밀 위치를 노출하지 않습니다. 사용자가 제출할 증거 사본은 별도 흐름으로 다루며, 제출 요건에 영향을 줄 수 있는 편집은 사용자에게 표시합니다.

## 내보내기 검토

사용자는 번호판과 촬영 일시·위치, 영상 구간, 의심 유형을 검토합니다. 자동 인식 결과가 불확실하면 미확인으로 표시하고, 요약문에는 검증되지 않은 값을 사실처럼 채우지 않습니다. 원본 해시는 파일 동일성 확인에 사용하며 사실 판정이나 위변조 방지의 완전한 보증으로 안내하지 않습니다.
