# RoadWitness 모델 실험

차량 탐지·추적, 차선 관계와 번호판 영역 검출의 실험 코드가 들어갈 예정 위치입니다. 모델 가중치와 실제 평가 영상은 별도로 보관합니다.

## 실험 기록

모델마다 이름·버전·출처·라이선스·해시, 입력 크기·전처리·출력 의미, 평가 세션 목록, 사건 단위 정확도와 기기별 지연을 기록합니다. 학습과 평가 자료는 주행 세션 단위로 분리합니다.

LiteRT와 ML Kit는 실행·인식 도구입니다. 필요한 도로 장면 모델과 번호판 성능은 직접 검증합니다. [기술 구조](../docs/ARCHITECTURE.md)와 [개발 계획](../docs/PLAN.md)을 참고합니다.
